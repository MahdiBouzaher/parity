# Parity

Parity translates SAS programs and Excel VBA macros to Python (pandas), runs the Python on a sample of your data, and checks that it gives the same numbers as the original. Every difference is listed and explained.

## Run the API

Needs Python 3.11 or newer.

```
cd api
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

The API listens on http://127.0.0.1:8000. Check it with `curl http://127.0.0.1:8000/api/health`.

## Run the web app

```
cd web
npm install
npm run dev
```

The dev server listens on http://localhost:5173 and proxies `/api` to the API on port 8000.

## Environment variables

Copy `.env.example` to `.env` in the repository root. Every value is optional.

| Variable | Purpose | Default |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | Key for the translation model. Without it the rule layer translates. | empty |
| `OPENROUTER_MODEL` | Model name | `openai/gpt-4o-mini` |
| `OPENROUTER_BASE_URL` | OpenAI-compatible endpoint | `https://openrouter.ai/api/v1` |
| `PARITY_RUN_TIMEOUT` | Seconds a translated program may run | `30` |
| `PARITY_DATA_DIR` | Where the database and uploads live | `./api/data` |
| `PARITY_CORS_ORIGINS` | Allowed browser origins, comma separated | the two local dev origins |

## Samples

The `samples` folder holds one SAS program, one VBA macro, `loans.csv` and the outputs the originals would produce.

These sample files are synthetic. `loans.csv` and the expected outputs were generated by `samples/generate_samples.py` and do not come from any real portfolio, SAS session or Excel file.

The expected outputs apply each original language's rules. SAS `ROUND` rounds a tie away from zero, and a blank value stays blank. A VBA loop counts a blank cell as zero. Some rows land exactly on a rounding tie so the SAS difference shows up in the demo.

Regenerate them with:

```
python samples/generate_samples.py
```

The script rewrites the files and checks the properties the demo depends on.

## Sandbox limits

The translated Python runs in a separate process with a temporary working directory, a time limit, CPU, memory and file size limits, and no network. Only pandas, numpy and a short list of standard modules can be imported, and files can only be opened inside the working directory.

This sandbox is best effort for local use. It is not a security boundary, so run Parity on your own machine and with code you trust.
